# 街並みジェネレーター（漫画背景資料用）

`index.html` をブラウザで直接開けば動きます（Three.js 埋め込み・オフライン可）。

## 機能
- 街の種類：住宅街／繁華街
- 道の種類：通常／路地（繁華街なら横丁）／川沿い／アーケード商店街
- 交差：なし／十字路／T字（右・左）／踏切（線路・遮断機・架線柱・電車）
- 道の形：カーブ（左右）と坂（上り・下り）。坂では敷地に擁壁が付く
- 小物：信号機、カーブミラー、標識、ガードレール、自販機、自転車、車、マンホール ほか
- 人：縮尺の目安になるマネキン（量を調整可）
- 時間と天気：朝／昼／夕方／夜、晴れ／曇り／雨、太陽の向き、影のオン・オフ

## 開発
ソースは `src/` に分かれています。編集したら次のコマンドで `index.html` を作り直してください。

```
node tools/build.mjs
```

- `src/template.html` … HTML の骨組み
- `src/style.css` … UI のスタイル
- `src/js/*.js` … アプリ本体（ファイル名順に連結）
- `vendor/three.r128.min.js` … Three.js r128（MIT）
