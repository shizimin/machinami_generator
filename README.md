# ストビュージェネレーター（漫画背景資料用）

`index.html` をブラウザで直接開けば動きます（Three.js 埋め込み・オフライン可）。

## 機能
- 街の種類：住宅街／繁華街／オフィス街（高層ビル・公開空地・街路樹・無電柱化）
- 道の種類：通常／路地（繁華街なら横丁）／川沿い／アーケード商店街
- 道の両側：左右それぞれ 街／山（間知ブロックの擁壁・落石防止柵・雑木林、たまに石段と鳥居）／海（護岸・砂浜か消波ブロック・防波堤と灯台）
- 遠くの山並み：なし／低い山／高い山（海の方角は自動で低くなり、島や岬のように見える）
- 交差：なし／十字路／T字（右・左）／踏切（線路・遮断機・架線柱・電車）。山側はトンネル、海側の線路は海の上の橋になる
- 道の形：カーブ（左右）と坂（上り・下り）。坂では敷地に擁壁が付く
- 小物：信号機、カーブミラー、標識、ガードレール、自販機、自転車、車、マンホール ほか
- 人：縮尺の目安になるマネキン（量を調整可）
- 時間と天気：朝／昼／夕方／夜、晴れ／曇り／雨、太陽の向き、影のオン・オフ

## 開発
ソースは `src/` に分かれています。編集したら次のコマンドで `index.html` を作り直してください。

```
node tools/build.mjs
```

- `src/template.html` … HTML の骨組み
- `src/style.css` … UI のスタイル
- `src/js/*.js` … アプリ本体（ファイル名順に連結）
- `vendor/three.r128.min.js` … Three.js r128（MIT）

共有ページ（claude.ai のアーティファクト）用には `node tools/build.mjs --artifact <出力先>` で別の版を書き出します。
共有ページの中ではダウンロードができないため、この版では撮影した画像を画面に表示し、長押し／右クリックで保存する形になります。
