# Google AI Studio で「撮影 → 写真化 → 線画化」アプリを作る

ストビュージェネレーター本体は GitHub Pages に置いたまま、Google AI Studio の
Build（アプリ作成）で「外側のアプリ」を作り、その中にストビューを埋め込む。
外側のアプリがナノバナナ（Gemini の画像生成・編集モデル）を呼ぶ。

## ストビュー側の仕組み（実装済み）

ストビューは iframe で埋め込まれると、親ページに `{ type: 'stv-ready' }` を送る
（撮影を頼まれるまで 1 秒ごとに送り直す。親から `{ type: 'stv-ping' }` を送ってもすぐ返す）。
親から次のメッセージを送ると、今の画面を画像にして返す。

```js
iframe.contentWindow.postMessage({ type: 'stv-capture', id: 1, format: 'jpeg' }, '*');
```

返ってくるメッセージ：

```js
{
  type: 'stv-capture-result',
  id: 1,
  image: 'data:image/jpeg;base64,...',   // 今の画面
  width: 1600, height: 900,
  settings: { mode, street, junction, sideL, sideR, time, weather, seed, curve, slope }
}
```

## AI Studio の Build に貼る指示文

```
漫画の背景資料を作るアプリを作ってください。日本語の UI でお願いします。

■ 画面構成
- 左（大きく）：iframe で https://shizimin.github.io/machinami_generator/ を表示する。
  これは 3D の街並みジェネレーター（ストビュージェネレーター）で、ユーザーはこの中で
  アングルを決める。
- 右（サイドパネル）：
  - 「撮影」ボタン
  - 撮影した元画像のサムネイル
  - 「写真化」ボタンと、写真化の指示文（編集できるテキスト欄、下の初期値を入れておく）
  - 「線画化」ボタンと、線画化の指示文（編集できるテキスト欄、下の初期値を入れておく）
  - 結果の画像（元画像・写真・線画を横に並べて比較できる）
  - 各画像に「保存」ボタン（PNG でダウンロード）

■ iframe との連携（postMessage）
- 「撮影」ボタン：iframe.contentWindow.postMessage({ type: 'stv-capture', id: <連番>, format: 'jpeg' }, '*')
- window の message イベントで { type: 'stv-capture-result', id, image, width, height, settings } を受け取る。
  image は data URL（JPEG）。settings はシード値などなので、ファイル名に使う。
- iframe からは読み込み完了時に { type: 'stv-ready' } が届く。届くまで撮影ボタンは押せないようにする。

■ AI 処理（@google/genai を使う。画像生成・編集ができる Gemini の画像モデル＝ナノバナナを使う）
- 写真化：撮影した画像＋写真化の指示文を渡し、画像を返してもらう。
- 線画化：写真化した画像＋線画化の指示文を渡し、画像を返してもらう。
- 処理中は進み具合がわかる表示を出し、失敗したら理由を表示する。

■ 写真化の指示文（初期値）
この画像の構図・建物の位置・遠近・カメラの高さをそのまま保って、日本の街並みを撮った実写写真にしてください。
建物・電柱・人・車を増やしたり消したりしないでください。窓や看板などの細部は写真らしく描き込んでください。
電線は描いてください。自然な光と影。

■ 線画化の指示文（初期値）
この写真を漫画の背景用の線画にしてください。白地に黒い線だけで、塗りやトーンは入れないでください。
手前の線は太く、奥の線は細く。構図と遠近は一切変えないでください。
```

## うまくいかないとき

- **iframe の中が表示されない**：アプリのプレビュー環境が外部サイトの埋め込みを禁止している可能性がある。
  その場合は、ストビューの `index.html` をアプリのファイルとしてアップロードし、
  iframe の src をそのファイルに変える（AI Studio に「public フォルダに index.html を置いて埋め込んで」と頼む）。
- **撮影しても何も起きない**：ストビューの GitHub Pages が、この連携機能の入った最新版になっているか確認する。
- **構図がずれる**：写真化の指示文で「構図を変えない」を強めるか、元画像と一緒に
  「この画像と同じ構図で」と2回伝える。
